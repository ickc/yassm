# Datasets

| File | Description | Source |
| --- | --- | --- |
| `Nile.dat` | Annual flow of the river Nile at Aswan, 1871–1970 | Durbin & Koopman, *Time Series Analysis by State Space Methods*; also R's `datasets::Nile` |
| `Prob2HW3DataStat248.csv` | The Nile series with missing values | STAT 248 homework 3 |
| `googletrends21Jan2016.csv` | Weekly worldwide Google Trends interest in "google", 2004–2016 | [Google Trends](https://trends.google.com/) |
| `SN_y_tot_V2.0.txt` | Yearly mean total sunspot number, 1700–2019 | WDC-SILSO, Royal Observatory of Belgium, Brussels, [CC BY-NC 4.0](https://www.sidc.be/SILSO/datafiles) |
| `Prob*HW*DataStat248.csv` | Homework datasets | Provided with the STAT 248 (UC Berkeley, spring 2022) homework |
